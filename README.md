The current web screenshots are generated by Playwright from the frontend app:

```bash
cd frontend
PLAYWRIGHT_BROWSERS_PATH=./.playwright-browsers npm run e2e:screenshots
```

## AI Coach Setup

The personal `LangVoyage Coach` conversation now uses the Gemini API through the Django backend.

Set these env vars before starting the backend:

```bash
export GEMINI_API_KEY=your_gemini_api_key
export GEMINI_MODEL=gemini-2.5-flash-lite
export GEMINI_TIMEOUT_SECONDS=20
```

If `GEMINI_API_KEY` is missing, the coach chat stays visible but replies with a configuration error message instead of a generated response.
