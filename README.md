# LangVoyage

LangVoyage is a language-exchange app with a Django backend, a React web frontend, and an Expo/React Native mobile client.

## Project Structure

- `backend/`: Django API, websocket/chat backend, media, and tests
- `frontend/`: React web app with Playwright E2E coverage
- `mobile/`: Expo/React Native mobile client scaffold

The current web screenshots are generated by Playwright from the frontend app:

```bash
cd frontend

```
